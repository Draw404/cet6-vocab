# 六级背词 · 艾宾浩斯复习（PWA 公开版）

一个不用注册、不用服务器、能装到手机桌面的背词小应用。
打开网页即可用，添加到主屏幕后和普通 App 一样全屏运行、离线可用。

## 功能

- **艾宾浩斯排期**：学会后第 1、2、4、7、15、30 天各复习一次，六轮全过毕业；逾期复习自动顺延到次日
- **当天重练（仿墨墨）**：当天第一次点「不认识」的词，当天记录为不认识（明天再复习），但会在当天队列里反复出现，直到当天连续点对 3 次才算过关；重练不改排期
- **卡片复习**：单词＋音标＋词性＋出处，先回忆再看释义和原句，点「认识 / 不认识」记录
- **自由加词**：网页表单随时添加自己的生词（可带原句和翻译）
- **导入 / 导出**：词库导出为 JSON 备份；导入支持「只加新词（不动已有进度）」和「覆盖恢复」两种模式
- **考试倒计时**：首页显示距考试天数，考试日期可自改（四级、考研等同样适用）
- **纯本地数据**：词库和进度只存在你自己设备的浏览器里，不上传任何服务器，没有账号、没有广告

## 使用

1. 用手机浏览器打开本站（GitHub Pages 地址）
2. （推荐）按页面底部「📲 装到手机桌面」的说明添加到主屏幕
3. 首次打开是空词库（不预设任何人的词表和考试日期）：可一键载入 3 个示例词（自编例句）先看效果，也可直接添加、导入自己的词表

⚠️ 在微信里打开的链接无法安装到桌面，请点右上角「···」→「在浏览器打开」。

## 数据与隐私

- 所有数据保存在浏览器 localStorage 中，开发者接触不到你的任何数据
- 换设备或清理浏览器数据前，请先用「💾 我的数据 → 导出备份」保存 JSON 文件，再在新设备上导入
- 内置演示例句为自编文本，不含任何考试真题内容；真题原句请通过导入功能使用你自己的材料

## 技术

- 原生 HTML/CSS/JS，无框架、无构建步骤：`index.html`（界面）+ `logic.js`（排期与重练逻辑）+ `seed.js`（演示种子）
- PWA：`manifest.json` + `service-worker.js`（离线缓存）+ `icons/`
- 本地开发/预览：任意静态服务器即可，如 `python3 -m http.server`
- 同一代码后续可经 Capacitor 打包为 Android APK
